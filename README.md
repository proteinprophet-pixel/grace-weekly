* **교회명**: 대한예수교장로회 한영교회 (담임목사: 송선우)

  3. 땅끝까지 선교하는 교회
* **조직 구성**:
  * 담임목사: 송선우 | 부목사: 신광은, 최선열 | 전도사: 여은영

  * 안수집사회 (회장 최진업 안수집사 외) & 권사회
* **찬양대 조직**:
  * **시온 찬양대**: 주일 2부(11:00) 대예배 찬양대 (지휘: 김남규, 반주: 문제철, 오르간: 서영숙, 대장: 조익한)
  * **임마누엘 찬양대**: 주일 오후(14:30) 찬양예배 찬양대 (권사 중심 찬양, 반주: 최신아, 대장: 김태형)
  * **헵시바 찬양대**: 수요 성서연구(19:30) 저녁예배 찬양대 (지휘: 신광은, 반주: 이지혜, 대장: 윤영임)

2. **탭 2: 오후·수요·기도**: 오후 찬양예배, 수요 성서연구, 금요 밤 기도회, 새벽기도회, 교회학교(유·초등부, 중·고등부, 청년회)

## 3. 접근성 기능 (Senior Accessibility)
* **글자 크기 조절**: `가+` / `가-` 돋보기 줌 버튼
* **음성 낭독 모드 (Speech Narration)**: `🔊 낭독` 버튼 클릭 시 주보 주요 내용 자동 음성 안내
* **카카오톡 및 링크 원클릭 공유**
* **빠른 로딩 (Pure Vanilla)**: 0.8초 이내 빠른 로딩 보장
